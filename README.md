# Octagon NodeJS MySQL Server

## Описание
Этот сервер на Node.js подключается к базе данных MySQL и реализует базовые CRUD операции с таблицей `Items`.

## Требования
- Node.js
- MySQL (XAMPP или другой сервер)
- npm пакеты: express, mysql2, nodemon

## Установка сервера
1. Склонируйте репозиторий
2. Выполните команду: npm install
3. Запустите MySQL сервер и создайте базу данных `ChatBotTests` и таблицу `Items` (если ещё не создали).

## Запуск сервера
Команда - npm start
или с автоперезапуском (nodemon):npm run dev

## Маршруты API

| Метод | Путь           | Описание                                           |
|-------|----------------|----------------------------------------------------|
| GET   | /getAllItems   | Возвращает все элементы в JSON формате             |
| POST  | /addItem       | Добавляет элемент. Параметры: `name`, `desc`       |
| POST  | /deleteItem    | Удаляет элемент. Параметр: `id`                    |
| POST  | /updateItem    | Обновляет элемент. Параметры: `id`, `name`, `desc` |

## Обработка ошибок
- При неправильных параметрах сервер возвращает `null`.
- Если объект не найден — возвращается пустой объект `{}`.
